# Project Overview

This repository contains a test automation framework using Cucumber, TypeScript, and Page Object Model (POM).

## Folder Structure

* **config**: Contains configuration files for different environments, URLs, and global framework settings.
* **dataBase**: This contains the images as requested in the test guidelines
* **features**: Stores Cucumber feature files (`.feature`) written in Gherkin syntax describing user behaviors and test scenarios.
* **fixtures**: Contains test data
* **pages**: Implements the Page Object Model (POM), containing page classes that map UI elements and interactions for individual web pages.
* **reports**: Automatically generated folder where test execution results, HTML reports, logs, and screenshots are stored.
* **scripts**: Contains the self-heal POC script as requested in the tets guidelines
* **utils**: Includes common helper functions, wrappers (such as custom loggers or API helpers), and shared utilities used across the framework.
